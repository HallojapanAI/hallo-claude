# ui — UI/UX đồng bộ hallo-web & hallo-admin

Không có lệnh gõ tay. Skill `design` (tự động): khi bạn xây mới, redesign hoặc chỉnh giao diện trong hallo-web /
hallo-admin, Claude nạp nguyên tắc chung (adaptive PC/Mobile, phân tầng thông tin, bảng dữ liệu tùy chỉnh,
badge trạng thái, vùng chạm, tách presentation state khỏi domain data) và đọc design token/component gốc ở
hallo-web để hai app dùng cùng một hệ thống.

Cài: `claude plugin install ui@hallo`
